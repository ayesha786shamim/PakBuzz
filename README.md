# <span style="color: #00B8D4;">PakBuzz</span> 🇵🇰

**PakBuzz** is a Python-based WhatsApp bot that fetches the latest news from Pakistan and sends it directly to your WhatsApp. Built using the Twilio API, it keeps you updated with the most important headlines in a matter of seconds.

## 🚀 Features

- 🇵🇰 Fetches the latest news from **Pakistan** only.
- 💬 Sends top headlines directly to **WhatsApp**.
- 🛠️ Simple setup with just a few lines of code.
- 🎙 Option to send news as **voice notes** (coming soon).

## 📋 Prerequisites

- 🔑 **Python 3.x** or higher
- 📝 **NewsAPI** account (Get your free API key [here](https://newsapi.org/))
- 📞 **Twilio** account (Set up WhatsApp sandbox [here](https://www.twilio.com/whatsapp))
- 🔐 **Twilio credentials** to send WhatsApp messages securely
